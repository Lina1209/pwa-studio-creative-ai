# PWA Studio — Creative AI

Творческая AI-видеостудия: от идеи и промта до готового видео.

## Сейчас в проекте

Первая версия frontend-оболочки на Vanilla JavaScript с адаптивным интерфейсом, PWA-манифестом и офлайн-кэшем.

- Главная творческая панель.
- Разделы создания видео, видеоредактора, сценария и сцен.
- Prompt Studio с демонстрационным шаблоном промта.
- Studio AI Companion — интерфейс будущего AI-помощника.
- Медиатека, голосовая мастерская и настройки (пока подготовленные разделы).
- Адаптивная навигация для компьютеров и смартфонов.
- Переключение тёмной и светлой темы.
- PWA Service Worker с относительными путями для GitHub Pages.

## Публикация на GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**.
4. Сохраните настройки и дождитесь публикации.

После включения Pages приложение будет доступно по адресу:

`https://lina1209.github.io/pwa-studio-creative-ai/`

## Важно о текущем этапе

Это стартовая frontend-оболочка. Формы и демонстрационные элементы интерфейса работают локально, но генерация сценариев, живой AI-чат, синтез речи, загрузка медиаматериалов и рендеринг видео пока не подключены.

Следующий этап — отдельный Python/FastAPI backend. Секретные API-ключи должны храниться только на сервере, а не в браузерном JavaScript.
